### AI Agent
- **Purpose:** Implements Minimax search algorithm with alpha-beta pruning, depth-limited search, terminal-state evaluations (+/- 10,000,000), and heuristic scoring (evaluates 4-cell windows horizontally, vertically, and diagonally, weighting center column).
- **Location:** `backend/ai_agent.py`
- **Dependencies:** `math`, `random`, `backend/game_engine.py`

### Game Engine
- **Purpose:** Pure game state operations: 6x7 board initialization, move validation, gravity piece dropping (`get_next_open_row`), and four-in-a-row victory detection across horizontal, vertical, and both diagonal directions.
- **Location:** `backend/game_engine.py`
- **Dependencies:** Python standard library

## Data Flow

1. User clicks a column on the board in the React frontend (`App.jsx:handleColumnClick`).
2. Frontend verifies column validity, calculates the drop row, places the Player piece (1: Red), checks for an immediate player win, and toggles `isThinking = true`.
3. Frontend sends `POST http://localhost:8000/api/ai-move` with JSON payload `{ board: list[list[int]], depth: int }` via `services/api.js`.
4. FastAPI `main.py:ai_move` receives the board and search depth, calling `minimax(board, depth, -inf, inf, True)`.
5. `ai_agent.py` explores legal moves, simulates board copies, evaluates terminal states and heuristics using `score_position` / `evaluate_window`, pruning branches via alpha-beta bounds.
6. `main.py` determines the corresponding drop row via `get_next_open_row` and returns `{ "column": col, "row": row }`.
7. Frontend updates state with AI piece (2: Yellow), checks for AI win condition, clears thinking indicator, and returns turn to Player.
